Floating Todo

A tiny Android to-do list that floats over other apps in a corner of the screen.

Features
Shows one item at a time
Swipe left or right to see the next item
+ adds an item
− deletes the current item and moves to the next one
Stays on screen until you close it
Install
Open the Actions tab of this repo and click the latest "Build APK" run.
Download the floating-todo-apk file and unzip it to get app-debug.apk.
Open the APK on your Android phone and allow installing from that source.
Open Floating Todo, tap Show floating list, and allow "Display over other apps".
Close it

Tap Close in the notification, or use the Close floating list button in the app.
